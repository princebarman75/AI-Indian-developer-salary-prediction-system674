📖 सभी महत्वपूर्ण परिभाषाएँ

1. Artificial Intelligence (AI)

AI अर्थात कृत्रिम बुद्धिमत्ता। यह ऐसी तकनीक है जिसमें कंप्यूटर को कुछ ऐसे काम करने योग्य बनाया जाता है जिनमें सामान्यतः मानव बुद्धि की आवश्यकता होती है।

2. Machine Learning (ML)

मशीन लर्निंग AI की एक शाखा है। इसमें कंप्यूटर डेटा से पैटर्न सीखकर अनुमान या निर्णय करना सीखता है।

3. Dataset

डेटासेट व्यवस्थित जानकारी का संग्रह होता है, जिसका उपयोग मॉडल को प्रशिक्षित करने और जाँचने के लिए किया जाता है।

4. Prediction

Prediction का अर्थ उपलब्ध जानकारी के आधार पर किसी परिणाम का अनुमान लगाना है।

5. Algorithm

एल्गोरिदम किसी समस्या को हल करने के लिए बनाए गए चरणों या निर्देशों का समूह होता है।

6. HTML

HTML एक मार्कअप भाषा है जो वेबसाइट का ढाँचा तैयार करती है।

7. CSS

CSS वेबसाइट के रंग, आकार, डिजाइन और लेआउट को नियंत्रित करती है।

8. JavaScript

JavaScript वेबसाइट को इंटरैक्टिव और गतिशील बनाने में मदद करती है।

9. Python

Python एक प्रोग्रामिंग भाषा है जिसका उपयोग AI, मशीन लर्निंग और डेटा विश्लेषण में किया जाता है।

10. Database

डेटाबेस जानकारी को व्यवस्थित तरीके से रखने और प्राप्त करने की प्रणाली है।

11. CTC

CTC का पूरा नाम Cost to Company है। यह कंपनी द्वारा कर्मचारी पर एक वर्ष में खर्च की जाने वाली कुल राशि होती है।

12. Dashboard

डैशबोर्ड एक ऐसा डिजिटल पेज है जहाँ महत्वपूर्ण जानकारी और आँकड़े एक जगह दिखाई देते हैं।

13. Model Training

मॉडल ट्रेनिंग में मशीन लर्निंग मॉडल को उदाहरण वाले डेटा से पैटर्न सीखने के लिए प्रशिक्षित किया जाता है।

14. Accuracy

Accuracy बताती है कि किसी मॉडल के परिणाम कितने सही हैं।
